Button and its helpers are the shared Richbox controls from the Password showcase (Richbox commit 90f63f19da4b5a58b72ae1319afda196db664c63). See LICENSE.richbox, LICENSE.upstream, and upstream.json.

The [Fluid Functionalism Input](https://www.fluidfunctionalism.com/r/input.json), icon registry, and font weights are reused from the Geist Rounded showcase. Input's imports are relative to this directory.

ShowcasePlayground extracts the layout, preview stage, theme toggle, and GitHub button from [mishanaer/password](https://github.com/mishanaer/password/tree/7675414), which uses the Richbox demo's layout and Deslop theme. The styles are scoped for the portfolio's Tailwind 3 setup and use the existing Deslop layout tokens. See LICENSE.password.

The download icon uses the unchanged [Deslop round/line arrow-to-line-down artwork](https://github.com/mishanaer/deslop/blob/88ea8399ceb5f27e9721d88fea27f85671c74bdc/primitives/icons/round/line/arrow-to-line-down.svg), which Deslop maps to `download`.
